# 🌍 GenSpeak

GenSpeak is the home of internet culture.

Discover, learn, and understand modern internet slang, memes, AI terminology, gaming language, and online trends through a premium, AI-powered knowledge platform.

## ✨ Features

- 📖 Internet culture dictionary
- 🤖 AI-powered explanations
- 🔍 Lightning-fast search
- 🧠 "Explain Like I'm 10" mode
- 📈 Trending internet words
- 🗂️ Categories & collections
- 📝 Editorial CMS
- 🌐 SEO-optimized knowledge base
- 🚀 Built with Next.js 15, Prisma, PostgreSQL & Vercel

## 🛠️ Tech Stack

- Next.js 15
- TypeScript
- Tailwind CSS
- Prisma ORM
- PostgreSQL (Neon)
- Auth.js
- Cloudinary
- Vercel
- AI Provider Abstraction (OpenAI / Gemini / Claude)
